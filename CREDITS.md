# Image credits

All lesson illustrations are photographs or scans of public-domain classical art
(sculptures, ancient vase paintings, mosaics, museum artifacts) or maps, sourced from
Wikimedia Commons via Wikipedia. Downloaded once and stored locally (flat in the repo
root, alongside everything else) so the app stays fully offline — see the main README
for why.

Regenerate or update this pipeline with `tools/fetch_images.py` (documents the same
process this file records the results of).
